# `/tickers` 증거 중심 첫 화면 설계

## 목표

`/tickers`에 처음 들어온 사용자가 별도의 서비스 설명을 읽지 않고도 다음을 한 화면에서 이해하고 행동하게 한다.

1. 주식 인플루언서가 과거에 긍정적으로 언급한 종목의 실제 결과가 추적되고 있다.
2. 상승한 사례만 보여주는 것이 아니라 완료된 상승·하락 결과가 모두 공개된다.
3. 과거 적중 이력이 있는 인플루언서들이 현재 긍정적으로 보는 종목을 바로 탐색할 수 있다.

첫 화면의 최우선 행동은 `검증된 후보` 행을 열어보는 것이다. 핵심 제품 지표는 `/tickers` 방문 대비 고유 종목 상세 탐색률이다.

## 승인된 방향

결과 중심 문구와 현재 후보 목록을 한 화면 안에서 분리해 사용한다.

- 완료된 상승 사례 영역의 헤드라인: `주식 인플루언서가 고르고, 실제로 오른 종목`
- 현재 후보 영역의 제목: `이들이 지금 보는 종목`
- 성공 사례는 20거래일 판정이 완료된 실제 상승 결과만 사용한다.
- 현재 후보는 상승·하락 및 아직 판정되지 않은 결과를 모두 같은 기준으로 보여준다.
- `주식 전문 인플루언서`는 자격 인증처럼 읽힐 수 있으므로 화면 문구에서는 `주식 인플루언서`를 사용한다.

이 구조는 결과를 먼저 보여주는 C안의 후킹을 유지하면서, 이미 오른 종목만 사후 선별해 추천하는 서비스처럼 보이지 않게 한다.

## 첫 화면 정보 구조

### 1. 압축된 결과 증거 영역

페이지 헤더 바로 아래에 세로 공간을 과도하게 차지하지 않는 증거 영역을 둔다.

- 작은 기준 문구: `20거래일 판정 완료 · 공개 원문 기반`
- 헤드라인: `주식 인플루언서가 고르고, 실제로 오른 종목`
- 최근 판정이 완료된 상승 사례 최대 3개
- 사례별 정보:
  - 티커와 회사명
  - 최초 긍정 의견 또는 의견 합의 날짜
  - 참여 인플루언서 수
  - 20거래일 실제 수익률
  - 확인 가능한 원문 수
- 전체 결과 요약:
  - 판정 완료 건수
  - 상승 건수
  - 하락 또는 보합 건수
  - 판정 기준 `20거래일 후 상승`

성공 사례는 수익률 상위가 아니라 **가장 최근에 판정 완료된 상승 사례** 순으로 선택한다. 이는 과도한 성공 사례 선별을 방지하면서 화면이 계속 갱신되는 느낌을 준다.

전체 결과 요약은 성공 사례와 같은 시각 영역 안에 둔다. 사용자는 상승 사례를 보면서 동시에 실패한 판정이 존재한다는 사실을 알 수 있어야 한다.

### 2. 현재 후보 영역

증거 영역 다음에 별도의 CTA나 긴 설명 없이 기존 후보 탐색이 바로 시작된다.

- 제목: `이들이 지금 보는 종목`
- 보조 문구: `과거 적중 이력과 완료 표본을 함께 봅니다.`
- 기본 뷰: `검증된 후보`
- 기본 노출: 상위 5개

후보 행은 다음 순서로 읽힌다.

1. 종목
2. 지금 모인 긍정 의견: 인플루언서 수와 중복 제거된 의견 수
3. 해당 인플루언서들의 과거 합산 적중률과 완료 표본 수
4. 현재 의견이 모인 뒤 실제 주가 결과
5. 원문 및 상세 근거 열기

`언급량`은 후보 발견 신호이며 신뢰의 직접 근거로 표현하지 않는다. 시각적으로 가장 큰 수치는 과거 적중률과 실제 주가 결과다.

## 적중 정의

사용자에게 표시하는 적중은 다음과 같이 단순하고 일관되게 정의한다.

- 대상: 신뢰 가능한 분석 상태의 긍정 의견
- 기준 시점: 의견 이벤트 다음 거래 세션의 조정 시가
- 판정 시점: 기준 시점으로부터 20번째 거래 세션의 조정 종가
- 적중: 원수익률이 `0% 초과`
- 미적중: 원수익률이 `0% 이하`
- 데이터 누락 또는 거래 정지 등 평가 불가: 적중률 분모에서 제외하고 별도 상태로 보존

기존 `signal_outcomes.verdict`는 ±2% 보합 구간을 사용하는 방향 일치 판정이므로, 본 화면의 `20거래일 후 상승 적중률`과 혼용하지 않는다. 화면용 적중 여부는 평가 가능한 `raw_return > 0`에서 별도로 계산한다.

## 중복 제거와 판정 단위

한 인플루언서가 같은 종목을 반복 언급해 적중 표본이 부풀려지지 않게 `인플루언서 × 종목 × 방향성 에피소드`를 한 번의 판정 단위로 사용한다.

- 첫 승인된 긍정 의견이 에피소드를 시작한다.
- 같은 긍정 방향의 반복 언급은 원문 수와 활동성에는 반영하지만 새 적중 표본을 만들지 않는다.
- 명시적인 방향 전환 또는 비방향성 전환으로 기존 의견이 종료되면 에피소드를 닫는다.
- 종료 뒤 다시 긍정 의견이 시작되면 새 에피소드가 된다.
- 계산 버전을 저장해 규칙 변경 시 재현 가능하게 한다.

현재 `consensus_signal_events`는 다수 의견의 합의 이벤트를 평가하는 모델이므로 개별 인플루언서 적중 이력을 직접 대체하지 않는다. 개별 방향성 에피소드와 20거래일 결과를 재현 가능한 별도 읽기 모델로 제공한다.

## 후보의 합산 적중률

현재 종목에 유효한 긍정 의견을 가진 인플루언서들의 판정 완료 에피소드를 최근 12개월 범위에서 합산한다.

- 표시 적중률: 합산 적중 건수 ÷ 합산 평가 가능 건수
- 표본 수: 합산 평가 가능 건수
- 최소 공개 표본: 10건
- 10건 미만: 퍼센트 대신 `검증 중 · N건` 표시
- 표본이 0건인 인플루언서는 의견 수에는 포함되지만 합산 적중률에는 영향을 주지 않는다.

후보 순위는 단순 퍼센트가 아니라 표본 수를 반영한 Wilson 하한값을 사용한다. 사용자는 복잡한 점수 대신 실제 적중률과 표본 수를 본다. 동률은 현재 긍정 인플루언서 수, 최근 의견 시각, 티커 순으로 결정한다.

## 성공 사례 선택 규칙

`실제로 오른 종목` 영역에 들어가는 사례는 다음 조건을 모두 충족해야 한다.

- 20거래일 결과가 평가 가능함
- 방향이 긍정임
- 원수익률이 0% 초과임
- 근거가 되는 공개 원문이 하나 이상 있음
- 결과 데이터와 원문이 화면 생성 시점보다 과거에 확정되어 있음

최대 3개를 `target_session_date` 최신순으로 선택한다. 동일 날짜는 판정 표본 수, 티커 순으로 정렬한다. 수익률이 큰 사례만 고르는 로직을 사용하지 않는다.

성공 사례 카드나 행에는 `최근 판정 완료 사례`라는 라벨을 붙여 선택 기준을 명확히 한다. `추천`, `매수`, `수익 보장`, `전문가 인증`을 암시하는 문구는 사용하지 않는다.

## 데이터 준비와 백필

현재 기본 후보는 모두 20거래일 판정 대기 상태이므로 예시 적중률을 제품에 노출하지 않는다. 출시 전에 공개적으로 확인 가능한 과거 의견과 가격 데이터를 보강한다.

1. 가능한 범위에서 최근 12개월의 원문과 분석 결과를 수집한다.
2. 승인 또는 자동 승인된 방향성 의견만 재생한다.
3. 인플루언서별 방향성 에피소드를 결정론적으로 생성한다.
4. 조정 시가와 조정 종가를 사용해 20거래일 결과를 계산한다.
5. 실행을 반복해도 중복되지 않도록 계산 버전과 자연 키를 사용한다.
6. 원문이 삭제되었거나 가격 데이터가 불완전하면 결측 상태로 남기고 성공 사례에서 제외한다.

백필 범위가 충분하지 않아 완료 표본 10건을 확보하지 못하면 적중률을 추정하거나 임의 데이터를 넣지 않는다.

## 데이터 부족 상태

완료된 상승 사례가 없으면 결과 중심 헤드라인을 그대로 보여주지 않는다.

- 대체 헤드라인: `주식 인플루언서 픽, 실제 결과를 추적합니다`
- 상태: `20거래일 검증 중`
- 성공 사례 공간에는 가장 오래 관찰 중인 후보와 남은 거래일을 표시
- 현재 후보 목록은 그대로 제공

후보별 합산 완료 표본이 10건 미만이면 `검증 중 · N건`으로 표시하고 적중률 순위의 상단에 올리지 않는다.

## 시각적 위계

- 기존의 차분한 분석 워크벤치 스타일을 유지한다.
- 큰 카드 묶음보다 구분선과 정렬된 숫자로 구조를 만든다.
- 성공 사례의 실제 수익률을 가장 큰 숫자로 사용한다.
- 상승은 녹색, 하락은 적색을 사용하되 텍스트 `상승`·`하락`을 함께 표시한다.
- 적중률 옆에는 항상 `N건`을 붙인다.
- 설명형 문단은 제거하고 기준은 짧은 보조 라벨 또는 툴팁으로 제공한다.
- 1440px 데스크톱 첫 화면에서 증거 영역과 현재 후보 최소 3행이 함께 보여야 한다.

## 상호작용

- 성공 사례 선택: 해당 종목 상세의 과거 결과/의견 근거 위치로 이동
- 현재 후보 행 선택: 기존 종목 상세 페이지로 이동
- 원문 선택: 새 탭에서 공개 원문 열기
- 전체 결과 요약 선택: 완료된 상승·하락 판정을 함께 보는 필터 상태로 이동
- 기존 관심종목 저장과 탭/필터 동작은 유지

행 전체 링크와 원문·관심종목 버튼의 클릭 영역이 충돌하지 않아야 한다. 키보드 포커스와 접근 가능한 이름을 제공한다.

## 반응형 동작

데스크톱:

- 성공 사례 최대 3개를 한 줄의 증거 스트립으로 표시
- 전체 결과 요약을 같은 줄의 끝 또는 바로 아래에 배치
- 현재 후보 최소 3행을 첫 뷰포트에 유지

모바일:

- 가장 최근의 성공 사례 1개와 전체 결과 요약만 먼저 표시
- 나머지 성공 사례는 `사례 더 보기`로 펼침
- 후보 행은 `종목 → 적중률·표본 → 현재 결과 → 의견 수` 순으로 세로 정렬
- 가로 스크롤을 만들지 않음

## 측정

핵심 지표:

- `/tickers` 고유 방문 대비 1개 이상의 고유 종목 상세를 연 비율

보조 지표:

- 방문당 고유 종목 상세 수
- 첫 종목 상세 열기까지 걸린 시간
- 성공 사례에서 상세로 이동한 비율
- 현재 후보에서 상세로 이동한 비율
- 원문 열기 비율
- 관심종목 저장 비율

가드레일:

- 적중률 또는 실제 결과가 없는 상태에서의 이탈률
- 상승 사례만 본 뒤 현재 후보를 탐색하지 않은 비율
- 잘못된 원문 또는 결과 신고 건수

## 접근성 및 신뢰 문구

- 색상만으로 결과를 전달하지 않는다.
- 수익률에는 `상승`, `하락`, `관찰 중`의 텍스트 상태를 함께 제공한다.
- 적중률 툴팁과 스크린리더 설명은 `긍정 의견 20거래일 후 주가가 상승한 비율, 판정 완료 N건`으로 통일한다.
- 마지막 데이터 갱신 시각을 노출한다.
- 모든 수익률은 과거 결과이며 투자 추천이 아니라는 고지를 페이지 하단에 유지한다.

## 범위

포함:

- 결과 중심 증거 영역
- 성공 사례 선택과 전체 판정 요약
- 인플루언서별 방향성 에피소드 및 20거래일 적중 판정
- 후보별 합산 적중률과 표본 기반 정렬
- 과거 의견·가격 백필
- 데이터 부족 상태
- 반응형·접근성·측정 이벤트

제외:

- 시장지수 대비 초과수익 적중률
- 5일·60일 다중 기간 선택
- 투자 추천 또는 매수/매도 신호
- 유료 인플루언서 인증
- 적중률만으로 미래 수익을 보장하는 표현

## 검증

도메인 테스트:

- 반복 긍정 언급이 하나의 에피소드로 합쳐짐
- 방향 전환 후 새 긍정 의견이 새 에피소드를 생성함
- 다음 거래일 조정 시가와 20번째 거래일 조정 종가를 사용함
- `raw_return > 0`만 적중으로 계산함
- 결측 결과가 적중률 분모에서 제외됨
- 합산 표본 10건 미만은 `검증 중`으로 표시됨
- Wilson 하한 순위가 작은 표본의 100%를 과대평가하지 않음

데이터 테스트:

- 백필 재실행이 중복 이벤트를 만들지 않음
- 모든 성공 사례에 공개 원문과 평가 가능한 가격 결과가 존재함
- 최근 판정 완료 순서가 결정론적임
- 전체 완료 건수가 상승·미적중·평가 불가 건수와 일치함
- 화면 생성 이후의 데이터가 과거 결과에 섞이지 않음

UI 및 상호작용 테스트:

- 성공 사례가 없을 때 대체 헤드라인과 검증 중 상태가 표시됨
- 성공 사례와 현재 후보의 결과 의미가 구분됨
- 상승·하락·관찰 중 상태가 색상 없이도 구별됨
- 성공 사례와 후보 행이 올바른 상세 위치로 이동함
- 원문과 관심종목 버튼이 행 전체 링크를 트리거하지 않음
- 1440px에서 현재 후보 최소 3행이 첫 뷰포트에 표시됨
- 모바일에서 가로 오버플로가 없음

## 출시 기준

- 실제 판정 완료 데이터만 제품 화면에 노출됨
- 성공 사례가 있는 경우 전체 상승·미적중 건수가 함께 표시됨
- 후보별 적중률은 표본 수와 함께 표시됨
- 표본 10건 미만은 순위에서 제외되며 `검증 중`으로 표시됨
- 상승·하락 및 평가 불가 판정이 재현 가능함
- 핵심 탐색 이벤트가 측정됨
